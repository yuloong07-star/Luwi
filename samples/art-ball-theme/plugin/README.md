# 示例外观 · 青瓷 (art 域)

协议第 10.1 节那一档的实物: **只做美术的人不需要一行代码**, 带一份 `theme/ball.json` 与几张图,
在设置页「浮标外观」那一行里挑一下, 球就换成这套画法。

## 包里有什么

| 在哪 | 是什么 |
| :-- | :-- |
| `plugin.json` | `kind: art`, 零能力零工具 |
| `plugin/theme/ball.json` | 每个状态一张图的路径 (`idle` / `listening` / `thinking` / `speaking` / `failed`) |
| `plugin/art/*.png` | 那五张图 (由 `tools/build-art.py` 生成) |
| `tools/build-art.py` | 想改配色就改这几行, 重跑一遍 |

## 两条要记住的

1. **多个主题插件可以同时装着, 同一时刻只生效一个** —— 换一个只重画, 不用重装任何东西
2. **读不到就回内置画法**: 插件被删掉 / 目录被手工改坏 / 图缺了一张, 球自己会退回内置那一颗,
   而"换一套图标生效; 删掉插件回退内置"正是这一档的验收判据

路径那两条纪律在这里同样管: 解出来的图必须落在插件目录里 (装的时候查一次, 读的那一刻再兜一次),
`../` 那种越界的写法装的时候就拒。
