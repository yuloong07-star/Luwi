# 鲸鱼娘 (art 域)

一份 `art` 插件的最小样板: **一包资源, 零代码, 零第二次安装**。

选型那四条规矩里它排第一条 —— "能用 `art` 表达的, 绝不写代码"。它能提供四样东西: 浮标外观
(`theme/ball.json`)、**桌面组件的内容** (`widget/widget.json`, 就是这一份)、声明式面板
(`panel/main.json`)、设置项声明。它拿不到任何系统权限, 能做的就是把图放到你看得见的地方。

## 这一份的形状

```
plugin.json             protocol / id / version / kind: art / toolPrefix / capabilities (空的)
widget/widget.json      占哪个宿主槽 (anim / image), 内容长什么样
art/dance-1/…           逐帧图: frame-00.png, frame-01.png … (名字与张数都是协议的一部分)
```

`widget.json` 里两个字段最要紧:

| 字段 | 含义 |
| :-- | :-- |
| `slot` | 占哪个宿主槽: `anim` (会动的形象) 或 `image` (图文卡片) |
| `frames` / `sets` | 帧图目录、张数、每秒几张; `sets` 有多份时**点一下换下一套** |

**路径纪律**: 包里所有指向自己的相对路径都查两遍 (装的时候一次、读图那一刻再一次), 不许绝对路径、
不许 `..`、不许反斜杠, 解出来必须落在插件目录里 —— 这一条在 `art` 域是硬要求, 因为它连编译都没有。

## 两条天生限制 (Android 的, 不是没做)

1. **组件名固定**: 选择器里写的是「Luwi 动画组件」, 插件自己的名字只在 Luwi 里看得见
2. **版式固定**: 只能用主 APK 预置的那两种槽; 加新槽要发一次主 APK 的版
