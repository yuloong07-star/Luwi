# archive —— 仓库里的历史归档

放**不再参与构建、但删了可惜**的那几份东西。它与工作区那一层 `D:\apk\archive\` (构建日志 / 提交草稿 /
旧 APK) 分开: 这一层是**跟仓库一起走**的历史代码。

| 子目录 | 放什么 | 什么时候进来的 |
| :-- | :-- | :-- |
| `samples/whale-widget/` | 鲸鱼娘桌面小组件那一份**伴侣 APK 样例** (协议 10.4 旧那一条路的实物; 方案 v2 起桌面组件默认走主 APK 的宿主槽) | 2026-10-11, 方案 v2 落地 |

两条纪律:

1. **归档不等于没人管**: `tools/check-plugins.mjs` 仍守着这里那份 `plugin.json` 与它 `describe()` 的
   一致性 —— 谁哪天照着它做, 照着的那一份得是对的
2. **归档的模块不再进 `settings.gradle.kts`** (目录挪进来时一起摘掉); 想重新构建它那份 APK, 用
   `luwi-plugins` 仓库里能构建的拷贝
